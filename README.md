# 🎲 Just Pick — 纠结终结器

一个中文决策小工具，帮助你做出愿意接受的选择。

## 在线使用

[点击打开纠结终结器](https://xuhaoxiang666450-collab.github.io/-/)

无需下载或登录，任何人都可以通过链接直接使用。

## 功能

- **帮我拍板**：从选项中随机选出一个答案。
- **听听内心**：通过看到答案后的第一反应，确认选择或改选。
- **认真比较**：设置关注因素、权重和评分，比较各选项得分。
- 提供六种场景模板，支持自定义问题与选项，适配手机和电脑。

## 使用

下载本仓库后，用浏览器打开 `index.html` 即可使用，无需安装依赖。

## 文件

- `index.html`：页面结构
- `style.css`：页面样式与响应式布局
- `app.js`：决策逻辑与交互

本项目使用原生 HTML、CSS 和 JavaScript。
